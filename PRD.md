# PRD - Running Calculator

## Overview
- **Product:** Web App Kalkulator Lari
- **Problem:** Pelari butuh tools untuk hitung pace, distance, time, dan race prediction
- **Users:** Pelari (beginner & advanced)
- **Success:** Akurasi perhitungan, mudah dipakai, mobile-friendly

## Features
### Core
- [ ] Pace Calculator
- [ ] Distance Calculator
- [ ] Time Calculator
- [ ] Race Time Prediction (Riegel formula)

### Presets
- 1K, 3K, 5K, 10K, 15K, 21.1K, 42.195K

## Technical
- React + Vite + Tailwind CSS
- Client-side only (no backend)
- Responsive design
